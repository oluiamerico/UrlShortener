# 🔗 Encurtador de URL / URL Shortener

Um encurtador de URL fullstack com React (frontend), Node.js + Express (backend) e PostgreSQL (banco de dados).

A fullstack URL shortener with React (frontend), Node.js + Express (backend), and PostgreSQL (database).


## ✨ Funcionalidades / Features
- Encurtamento de URLs longas / Shorten long URLs
- Redirecionamento automático / Automatic redirection
- Interface responsiva / Responsive UI
- Copiar URL com um clique / One-click copy

## 🛠️ Tecnologias / Technologies
**Frontend:**
- React.js
- Axios
- CSS moderno / Modern CSS

**Backend:**
- Node.js
- Express
- PostgreSQL
- CORS
